Entrar com GitHub

Só entra quem tem permissão de escrita no repositório do site. O próprio GitHub confere o acesso.

Como conseguir o token
  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: "Only select repositories" → só o repositório do site.
  3. Permissions → Contents: "Read and write". Escolha uma validade (ex.: 90 dias).
  4. Gere, copie e cole aqui. Guarde o token como uma senha.
